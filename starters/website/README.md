# My website

This is a simple website. The page is in `site/index.html`.

- **Try it:** press **Try it** on the project page in the Foundry to open the site.
- **Look at it yourself:** run `node server.mjs`, then open the address it prints.
- **Test it:** run `node --test`.
- **Pack it:** the release recipe in `.factory/release-build.yaml` makes a `.tar.gz` file of the site.

You can ask the Foundry to change the page. It needs Node.js and nothing else.
