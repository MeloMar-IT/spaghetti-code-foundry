Shared metrics

Each account is asked once, on Today, whether the metrics of its runs may be shared. You can change your answer at any time: open the account menu, then Account settings.

What is shared: numbers only, once a day. How many runs started, finished and failed, how long they took, the tokens and cost, the names of built-in flows, steps and models, the install id, the Foundry version and the day.

What is never shared: your code, tasks, step output, the text of a change, names of people, e-mail addresses, repository names, branch names or paths.

Where it goes: once a day, after the day has ended (UTC), the report of that day is sent to spaghetti-code-foundry.com. When the last account says no, or an admin switches sharing off, the install asks the receiver to delete what it sent and gets a new install id.

Only the runs of accounts that said yes count. Service accounts are never asked and never count.

An admin can switch sharing off for the whole install in Settings, under Metrics sharing. Then nobody is asked, nothing is sent, and the answers given are kept for when it is switched on again.

See what would be shared

On the computer that runs the Foundry, the command scf metrics preview prints the report of one day exactly as it would be shared. It sends nothing.

In the web interface, What is shared on Today and in Account settings shows the same report for your own runs (an admin sees the report of the whole install), and the last report that was sent with its time and the receiver's answer.
