# Small changes

- Do what was asked, nothing more and nothing less.
- Do not refactor code that is unrelated to the task.
- Match the naming, comments and style of the surrounding code.
- Prefer editing existing files over adding new ones.
- Read a file before you edit it.
- Add or update tests for what you change.
- Run the tests before you finish, and fix what you broke.
- Say plainly what you changed and what you did not do.
